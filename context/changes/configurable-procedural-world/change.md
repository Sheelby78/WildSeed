Roadmap slice S-01. Visitor can configure world parameters (seed, map size, populations, vegetation/water density, mutation params) via presets + advanced panel, generate a deterministic procedural world, and see it rendered with PixiJS (color-coded tile grid) with pan/zoom and regeneration support.
